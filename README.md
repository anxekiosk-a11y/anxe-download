# anxe for Windows

Downloads of the anxe shop app: customers send files to your print shop from their phone,
and anxe prints them on your printer.

**Download:** https://printshop.anxe.in/download (always the latest version)

Set up your shop at https://printshop.anxe.in, then install this app on the computer that
is connected to your printer and enter the pairing code from your anxe account.

Each release lists the file's SHA-256 so you can check your download.
